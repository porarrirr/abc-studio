プライバシーポリシー

ABC Studio は利用者のプライバシーを尊重し、不要な情報収集を行わない設計を徹底しています。

最終更新日：2026年10月9日

プライバシーの基本原則

完全ローカル処理 楽譜の解析、描画、音声合成はすべてデバイス内で行われ、外部サーバーへ送信されることはありません。
追跡・広告ゼロ アプリ内に広告、行動追跡SDK、アクセス解析ライブラリは一切組み込まれていません。
音楽はあなたのもの 作成・編集した楽譜やレンダリングした音声の権利は100%あなたに帰属します。

porari（以下「運営者」）は、ABC Studio（以下「本アプリ」）およびABC Studioの案内サイト（以下「本サイト」）における情報の取り扱いを、次のとおり説明します。

1. 本アプリでの情報の取り扱い

本アプリは iOS 17 以降で動作するオフラインアプリです。ABCの解析、譜面の描画、演奏の処理はすべて端末内で行います。本アプリにアカウント登録機能、広告、アクセス解析SDK、トラッキング機能、開発者への自動クラッシュ報告機能はありません。本アプリから楽譜や利用状況などを運営者へ送信することは一切ありません。

2. 端末内に保存される情報

本アプリは、機能の提供と次回起動時の状態復元のため、次の情報のみを端末内のアプリ専用保護領域に保存します。これらを本アプリから運営者へ送信することはありません。

  • 現在開いているABCテキストと編集中の下書き、最後に開いたファイル名
  • 楽譜の表示倍率（ズーム倍率）と再生位置への自動追従設定
  • アプリ内ライブラリに保存したABCファイル、および各曲の表示名、作成日時、曲数

ライブラリの曲はアプリ内でいつでも個別に削除できます。また、編集中の下書きやABCテキストはクリア操作で消去できます。本アプリを端末からアンインストールすると、アプリ用保存領域のデータも通常は端末から完全に消去されます（iOSの「Appを取り除く」機能を使用した場合は書類とデータが保持される場合があります）。

共有用の ABC、PDF、PNG、MIDI、WAV ファイルを作成するときは、端末内の一時領域に一時ファイルを作成します。これらはOSのキャッシュクリア機能により定期的に削除されます。共有先に保存したファイルは、保存先の管理下に置かれます。

iCloud や Mac / PC へのバックアップを有効にしている場合、本アプリのローカルデータがバックアップに含まれることがあります。バックアップの暗号化や対象管理は端末の設定および Apple のサービス仕様に従います。詳しくは Apple の「iCloud バックアップの対象」 をご確認ください。

3. ファイルとクリップボードの扱い

ファイルを読み込む際は、利用者が iOS のファイル選択画面で明示的に選んだ .abc またはテキストファイルのみを本アプリが読み取ります。「クリップボードから読み込む」を選んだ場合のみクリップボードのテキストを読み取り、また「診断結果のコピー」を選んだ場合のみ診断テキストをクリップボードに書き込みます。これらのデータはすべてアプリ内部で完結して処理され、外部送信されません。

4. 書き出し、共有、外部リンク

書き出しや共有は利用者の明示的なタップ操作によってのみ開始されます。本アプリは iOS 標準の共有シートを表示し、利用者が選択したアプリ（メール、AirDrop、ファイル、各種クラウド等）へファイルを渡します。共有先でのデータの取り扱いは、それぞれのサービスのプライバシー方針に従います。

サポート、プライバシー、GitHub へのリンクを開くと、iOS に設定された標準ブラウザやメールアプリが起動します。外部サイトを開くと当該サイトへの通信が発生し、メールはお客様がメールアプリから送信操作を行った場合にのみ送信されます。

5. お問い合わせで受け取る情報

利用者がメールで問い合わせを行った場合、送信元のメールアドレス、本文、添付ファイル、およびそれらに含まれる情報が運営者の受信メールサーバーに届きます。運営者はこれらを返信、サポート、不具合調査、および対応に必要な記録のためにのみ利用し、販売や広告目的で第三者へ提供・利用することはありません。

過去のお問い合わせ履歴の確認や削除を希望される場合は、プライバシー窓口 へご連絡ください。なお、機密情報や問い合わせに不要な個人情報はメールに含めないようお願いいたします。

6. 本サイトと外部サービス

本案内サイトには、運営者が設置したアクセス解析ツール、広告タグ、Cookie を発行するトラッキングスクリプトは一切存在しません。本サイトは GitHub Pages でホスティングされています。GitHub はコンテンツ配信とインフラセキュリティ確保のため、アクセス元の IP アドレスやリクエストログを処理する場合があります。詳しくは GitHub のプライバシーステートメント をご確認ください。

App Store、iOS の診断共有設定、iCloud バックアップなど Apple が提供する基盤サービスの取り扱いは、Apple のプライバシーポリシー に従います。

7. 児童の情報

本アプリから運営者へ個人情報を送信する機能はありません。お子様が本アプリを利用される場合も個人情報の収集は行われません。お問い合わせの際にお子様の情報が含まれる場合は、サポートに必要な範囲でのみ取り扱います。保護者の方は不要な個人情報をメールに記載しないようご配慮ください。

8. ポリシーの変更

本アプリや本サイトの仕様変更、法令の改正等に伴い本ポリシーを変更する場合は、本ページを更新し、冒頭の最終更新日を改定します。
