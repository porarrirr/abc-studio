# Security policy

For vulnerabilities, contact **musicabc@rarari.org** with the subject
`ABC Studio security`. Please report vulnerabilities privately before opening
a public issue. Include the affected version, reproduction steps, and impact;
omit real private scores and credentials.

The current source on `main` is maintained. This is an offline app, but imported
ABC files still need to be treated as untrusted input. Reports about parsing,
file handling, or resource exhaustion are welcome. Response times are not
guaranteed.
