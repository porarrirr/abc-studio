# Store screenshots

Captured on 2026-10-09 from the running app, not designed UI mockups.

- `raw/iphone-score.png`: iPhone 17 Pro, 1206×2622, iOS 27.0.
- `raw/ipad-score.png`: iPad Pro 13-inch (M5), 2064×2752, iPadOS 27.0.
- `generated/`: original outputs from the built-in ImageGen tool.
- `ja/`: final PNGs sized for the corresponding App Store screenshot slots.
- `prompts.json`: complete built-in ImageGen prompt set and input references.

The AI treatment adds Japanese captions and a cream/teal frame around the real
app screen. Results were visually compared against the references for title,
controls, notation, and device layout. Final resizing uses macOS `sips`.
The images claim no price, rankings, ratings, or unsupported features.
Original screenshots are retained for traceability and any future correction.
