# Contributing to ABC Studio

Issues and pull requests are welcome. Explain the expected behavior, actual
behavior, iOS / Xcode version, and a minimal ABC example that you may share.
Do not include copyrighted scores without permission or personal information.

1. Fork the repository and create a focused branch.
2. Open `ABCStudio.xcodeproj` in Xcode. No package dependency installation is needed.
3. If changing project configuration, edit `project.yml` and run `xcodegen generate`.
4. Run the unit tests and relevant UI tests using the `ABCStudio` scheme.
5. Describe the problem, resulting behavior, and validation in your pull request.

Keep the implementation native and offline. Preserve third-party attribution.
By submitting a contribution, you agree to license your original contribution
under this repository's MIT License. Third-party material must have compatible
terms and an explicit source and notice.

For general questions: musicabc@rarari.org.
